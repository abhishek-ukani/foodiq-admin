# FoodIQ Admin - Project Instructions

## Mobile-First Priority & Guidelines

1. **Mobile-First Development**:
   - Build and optimize interfaces for **mobile first**. Ensure layouts adapt seamlessly to small screens.
   - Touch targets must be at least 44px for easy mobile usage.

2. **Dedicated Mobile UI When Needed**:
   - If responsive layouts become compromised or difficult to manage on mobile, create separate dedicated UI views for mobile.
